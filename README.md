# 🌍 WiFi Spot Mapper  

A web app that lets users **crowdsource free/public WiFi locations** on an interactive map. Built with Leaflet.js.  

## ✨ Features  
- **Add WiFi spots** (name, password status, location)  
- **View all hotspots** on a map with clickable markers  
- **Toggle layers** (map styles, WiFi markers)  
- **Auto-location** (GPS or manual map click)  

## 🛠️ Tech Stack  
- **Frontend**: HTML5, CSS3, Tailwind, JavaScript (Leaflet.js)  
- **Backend**: Java (Spring Boot)  
- **Data Storage**: PostgreSQL  

## 🚀 Setup  
1. Clone the repo:  
   ```bash  
   git clone https://github.com/your-username/wifi-spot-mapper.git  
   ```  
2. Open `index.html` in a browser (no server needed).  

## 📂 File Structure  
```  
wifi-spot-mapper/

└── js/

```

## 🔧 How to Use  
1. **Add a WiFi Spot**:  
   - Click the map to set location  
   - Fill the form (Identification, SSID, password optional, Location)  
   - Submit → marker appears!  

2. **View Hotspots**:  
   - Click any marker to see WiFi details  
   - Toggle layers via the control panel
